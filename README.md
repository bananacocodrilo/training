Durable source of truth for the training project.

- Outdoor **7A sport climbing within 12 months**

## Programming philosophy
RP Strength-inspired, not an RP template:
- Start near **MEV**.
- Increase volume/effort only when performance and recovery support it.
- Build toward individualized **MAV**.
- Deload when fatigue/recovery indicate it.
- Climbing fatigue must be included in the recovery budget.

Muscle priorities:
- **High:** lateral delts, biceps, triceps
- **Medium-high:** upper chest
- **Medium:** back
- **Maintain:** quads, hamstrings, calves, core, bench strength

Important: climbing provides essentially no meaningful triceps hypertrophy stimulus and surprisingly little biceps stimulus for this user, so direct arm work is required.

## First mesocycle exercise framework
### Gym A — Push + Arms
1. Bench press
2. Incline DB press
3. Cable lateral raise
4. Cable curl
5. Seated cable triceps pushdown/extension

### Gym B — Legs + Core
1. Leg press
2. Romanian/stiff-leg deadlift
3. Lying/seated leg curl
4. Over-the-knee reverse lunge / unilateral movement
5. Calf raise
6. Pallof press

### Gym C — Upper Physique
1. Incline DB press
2. Technogym low row / chest-supported row
3. Cable lateral raise
4. Rear-delt fly
5. Cable curl
6. Cable triceps extension/pushdown

Keep lower-body volume maintenance-oriented. Avoid unnecessary grip-intensive accessories and excessive pulling volume. Be conservative with heavy hinges because of back history.

## First proper mesocycle gym session
- Bench: **90×8×3 @ RIR 2**
- Incline DB bench: **26×12×2 @ RIR 1**
- Cable curl: **22.5×15×3 @ RIR 3**
- Seated cable triceps pushdown: **30×12×2 @ RIR 2**
- Cable lateral raise: **7.5×12×3 @ RIR 5**

Interpretation: bench strength retention is excellent. Incline was harder than intended, so compounds should not routinely be taken to RIR 1 during the cut. Curl load is appropriate. Lateral raise load was too easy and likely needs increasing if technique remains clean.

## Planned climbing structure
### Climb A — Limit + Fingers
Progressive warmup; Kilter/MoonBoard limit bouldering; long rests; fingerboard after establishing a safe baseline.

### Climb B — Technique + Volume
Mostly submaximal routes; footwork, positioning, efficiency, route reading; avoid turning every session into projecting.

### Climb C — Sport / Power-Endurance
Progress toward route intervals, linked climbing, 4×4-style work, sustained hard sections and eventually redpoint-specific capacity.
